Este sistema ha sido desarrollado mediante una arquitectura MVC, empleando las siguientes herramientas:

PostgreSQL

Base de Datos Relacional que contiene la información de los alumnos y estudiantes.

Python

Empleado principalmente para realizar consultas a la base de datos, empleando Flask como micro-framework back-end.

Bootstrap

Framework CSS empleado para los estilos de la página web.
